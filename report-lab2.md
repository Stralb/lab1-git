Semantic HTML Fundamentals Lab Report

This lab exercise provided hands-on experience with semantic HTML5 elements, enhancing my understanding of how to structure web content in a meaningful way. The task involved creating a personal portfolio page using semantic tags such as <header>, <nav>, <main>, <section>, <article>, and <footer>. By completing this assignment, I deepened my knowledge of structuring a webpage with a clear hierarchy and making it more accessible and SEO-friendly.

Through this task, I learned how to use semantic elements to organize content logically, including adding a welcome message in the <header>, creating a navigation menu with <nav>, and structuring the main content into sections like "About Me" and "Latest Project". I also learned the importance of using headings to organize content and the role of the <footer> for providing necessary information. The webpage was successfully deployed on GitHub Pages, and can be viewed at 
https://stralb.github.io/lab1-git/2613224-lab2.html.

This lab strengthened my skills in creating well-structured webpages using semantic HTML, which is crucial for building accessible and easily navigable sites. It reinforced the importance of organizing content in a way that improves readability and SEO, and it demonstrated how to implement these practices in real-world scenarios.
